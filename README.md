## 🎯 What is Arabic Typing Test?

Arabic Typing Test is a browser-based tool for practicing Arabic keyboard typing and measuring typing performance.

The test displays an Arabic passage and compares the user's input with the target text while they type. Performance statistics are updated during the test, allowing users to see their typing speed, accuracy, and mistakes.

The project is designed to make Arabic typing practice simple, fast, and accessible from both computers and mobile devices.

---

## 📊 Statistics

The test provides several real-time measurements:

| Statistic | Description |
|---|---|
| **WPM** | Words typed per minute |
| **CPM** | Characters typed per minute |
| **Accuracy** | Percentage of correctly typed characters |
| **Errors** | Number of incorrect characters |

These statistics are intended to give the user a quick overview of their typing performance.

---

## ⏱️ Test Modes

Choose between three available test durations:

- **1 minute** — quick practice
- **3 minutes** — standard practice
- **5 minutes** — extended practice

The timer starts when typing begins.

---

## 📝 Practice Texts

The project includes **100 Arabic practice texts** covering different subjects and writing styles.

The texts are designed to provide variety so that users do not repeatedly practice the same paragraph.

Each new test can load a different passage, making the practice experience less repetitive.

---

## ⌨️ Typing Feedback

The interface provides immediate visual feedback while typing.

- The current character is tracked precisely.
- Incorrect characters are highlighted.
- The typing caret follows the current Arabic character.
- Arabic text remains rendered as connected Arabic text rather than being split into isolated letters.

Special attention was given to Arabic text direction and character shaping because Arabic letters can change their visual form depending on their position within a word.
